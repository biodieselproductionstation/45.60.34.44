<h2 class="wp-block-heading heading-anchor" id="windows-admin-center-scenarios">Windows Admin Center scenarios</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Here are a few things you can use Windows Admin Center for:</p>
<!-- /wp:paragraph -->

<!-- wp:list -->
<ul class="wp-block-list"><!-- wp:list-item -->
<li><strong>Simplify server management</strong>: Manage your servers and clusters with modernized versions of familiar tools such as Server Manager. Install in under five minutes and manage servers in your environment immediately, no extra configuration required. For details, see <a href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/understand/what-is">What is Windows Admin Center?</a></li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>Work with hybrid solutions</strong>: Integration with Azure helps you optionally connect your on-premises servers with relevant cloud services. For details, see <a href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/">Azure hybrid services</a>.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>Streamline hyperconverged management</strong>: Streamline management of Windows Server hyperconverged clusters. Use simplified workloads to create and manage VMs, Storage Spaces Direct volumes, Software-Defined Networking, and more. For more information, see <a href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/use/manage-hyper-converged">Manage HCI</a>. For Azure Local management, see the <a href="https://learn.microsoft.com/en-us/azure/azure-local/overview">Azure Local documentation</a>.</li>

<h1 class="wp-block-heading" id="manually-deploy-windows-admin-center-in-azure-for-managing-multiple-servers">Manually deploy Windows Admin Center in Azure for managing multiple servers</h1>
<!-- /wp:heading -->

<!-- wp:list {"className":"metadata page-metadata"} -->
<ul class="wp-block-list metadata page-metadata"><!-- wp:list-item -->
<li>นำไปใช้กับ: ✅ Windows Admin Center, ✅ Windows Admin Center Preview</li>
<!-- /wp:list-item --></ul>
<!-- /wp:list -->

<!-- wp:heading {"className":"title is-6 margin-block-xs"} -->
<h2 class="wp-block-heading title is-6 margin-block-xs" id="ms--in-this-article">ในบทความนี้</h2>
<!-- /wp:heading -->

<!-- wp:list {"ordered":true,"className":"border-left padding-left-xxs"} -->
<ol id="content-well-in-this-article-list" class="wp-block-list border-left padding-left-xxs"><!-- wp:list-item -->
<li><a class="" href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/deploy-wac-in-azure#deploy-using-script">Deploy using script</a></li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><a class="" href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/deploy-wac-in-azure#deploy-manually-on-an-existing-azure-virtual-machine">Deploy manually on an existing Azure virtual machine</a></li>
<!-- /wp:list-item --></ol>
<!-- /wp:list -->

<!-- wp:paragraph -->
<p>This article describes how to manually deploy Windows Admin Center in an Azure VM for use in managing multiple Azure VMs. To manage a single VM, instead use the Windows Admin Center functionality built into the Azure portal, as described in&nbsp;<a href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/manage-vm">Use Windows Admin Center in the Azure portal</a>).</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a class="anchor-link docon docon-link" href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/deploy-wac-in-azure#deploy-using-script"></a></p>
<!-- /wp:paragraph -->

<!-- wp:heading {"className":"heading-anchor"} -->
<h2 class="wp-block-heading heading-anchor" id="deploy-using-script">Deploy using script</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>You can download&nbsp;<a href="https://aka.ms/deploy-wacazvm">Deploy-WACAzVM.ps1</a>&nbsp;which you will run from&nbsp;<a href="https://shell.azure.com/">Azure Cloud Shell</a>&nbsp;to set up a Windows Admin Center gateway in Azure. This script can create the entire environment, including the resource group.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/deploy-wac-in-azure#deploy-manually-on-an-existing-azure-virtual-machine">Jump to manual deployment steps</a></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a class="anchor-link docon docon-link" href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/deploy-wac-in-azure#prerequisites"></a></p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":3,"className":"heading-anchor"} -->
<h3 class="wp-block-heading heading-anchor" id="prerequisites">Prerequisites</h3>
<!-- /wp:heading -->

<!-- wp:list -->
<ul class="wp-block-list"><!-- wp:list-item -->
<li>Set up your account in <a href="https://shell.azure.com/">Azure Cloud Shell</a>. If this is your first time using Cloud Shell, you will be asked you to associate or create an Azure storage account with Cloud Shell.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li>In a <strong>PowerShell</strong> Cloud Shell, navigate to your home directory: <code>PS Azure:\> cd ~</code></li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li>To upload the <code>Deploy-WACAzVM.ps1</code> file, drag and drop it from your local machine to anywhere on the Cloud Shell window.</li>
<!-- /wp:list-item --></ul>
<!-- /wp:list -->

<!-- wp:paragraph -->
<p>If specifying your own certificate:</p>
<!-- /wp:paragraph -->

<!-- wp:list -->
<ul class="wp-block-list"><!-- wp:list-item -->
<li>Upload the certificate to <a href="https://learn.microsoft.com/en-us/azure/key-vault/key-vault-whatis">Azure Key Vault</a>. First, create a key vault in Azure portal, then upload the certificate into the key vault. Alternatively, you can use Azure portal to generate a certificate for you.</li>
<!-- /wp:list-item --></ul>
<!-- /wp:list -->

<!-- wp:paragraph -->
<p><a class="anchor-link docon docon-link" href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/deploy-wac-in-azure#script-parameters"></a></p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":3,"className":"heading-anchor"} -->
<h3 class="wp-block-heading heading-anchor" id="script-parameters">Script parameters</h3>
<!-- /wp:heading -->

<!-- wp:list -->
<ul class="wp-block-list"><!-- wp:list-item -->
<li><strong>ResourceGroupName</strong> - [String] Specifies the name of the resource group where the VM will be created.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>Name</strong> - [String] Specifies the name of the VM.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>Credential</strong> - [PSCredential] Specifies the credentials for the VM.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>MsiPath</strong> - [String] Specifies the local path of the Windows Admin Center MSI when deploying Windows Admin Center on an existing VM. Defaults to the version from <a href="https://aka.ms/WACDownload">https://aka.ms/WACDownload</a> if omitted.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>VaultName</strong> - [String] Specifies the name of the key vault that contains the certificate.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>CertName</strong> - [String] Specifies the name of the certificate to be used for MSI installation.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>GenerateSslCert</strong> - [Switch] True if the MSI should generate a self signed ssl certificate.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>PortNumber</strong> - [int] Specifies the ssl port number for the Windows Admin Center service. Defaults to 443 if omitted.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>OpenPorts</strong> - [int[]] Specifies the open ports for the VM.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>Location</strong> - [String] Specifies the location of the VM.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>Size</strong> - [String] Specifies the size of the VM. Defaults to "Standard_DS1_v2" if omitted.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>Image</strong> - [String] Specifies the image of the VM. Defaults to "Win2016Datacenter" if omitted.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>VirtualNetworkName</strong> - [String] Specifies the name of the virtual network for the VM.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>SubnetName</strong> - [String] Specifies the name of the subnet for the VM.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>SecurityGroupName</strong> - [String] Specifies the name of the security group for the VM.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>PublicIpAddressName</strong> - [String] Specifies the name of the public IP address for the VM.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li><strong>InstallWACOnly</strong> - [Switch] Set to True if WAC should be installed on a pre-existing Azure VM.</li>
<!-- /wp:list-item --></ul>
<!-- /wp:list -->

<!-- wp:paragraph -->
<p>There are 2 different options for the MSI to deploy and the certificate used for MSI installation. The MSI can either be downloaded from aka.ms/WACDownload or, if deploying to an existing VM, the filepath of an MSI locally on the VM can be given. The certificate can be found in either Azure Key Vault or a self-signed certificate will be generated by the MSI.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a class="anchor-link docon docon-link" href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/deploy-wac-in-azure#script-examples"></a></p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":3,"className":"heading-anchor"} -->
<h3 class="wp-block-heading heading-anchor" id="script-examples">Script Examples</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>First, define common variables needed for the parameters of the script.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>PowerShell<code class="lang-PowerShell">$ResourceGroupName = "wac-rg1" $VirtualNetworkName = "wac-vnet" $SecurityGroupName = "wac-nsg" $SubnetName = "wac-subnet" $VaultName = "wac-key-vault" $CertName = "wac-cert" $Location = "westus" $PublicIpAddressName = "wac-public-ip" $Size = "Standard_D4s_v3" $Image = "Win2016Datacenter" $Credential = Get-Credential</code></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a class="anchor-link docon docon-link" href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/deploy-wac-in-azure#example-1-use-the-script-to-deploy-wac-gateway-on-a-new-vm-in-a-new-virtual-network-and-resource-group-use-the-msi-from-akamswacdownload-and-a-self-signed-cert-from-the-msi"></a></p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":4,"className":"heading-anchor"} -->
<h4 class="wp-block-heading heading-anchor" id="example-1-use-the-script-to-deploy-wac-gateway-on-a-new-vm-in-a-new-virtual-network-and-resource-group-use-the-msi-from-akamswacdownload-and-a-self-signed-cert-from-the-msi">Example 1: Use the script to deploy WAC gateway on a new VM in a new virtual network and resource group. Use the MSI from aka.ms/WACDownload and a self-signed cert from the MSI.</h4>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>PowerShell<code class="lang-PowerShell">$scriptParams = @{ ResourceGroupName = $ResourceGroupName Name = "wac-vm1" Credential = $Credential VirtualNetworkName = $VirtualNetworkName SubnetName = $SubnetName GenerateSslCert = $true } ./Deploy-WACAzVM.ps1 @scriptParams</code></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a class="anchor-link docon docon-link" href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/deploy-wac-in-azure#example-2-same-as-1-but-using-a-certificate-from-azure-key-vault"></a></p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":4,"className":"heading-anchor"} -->
<h4 class="wp-block-heading heading-anchor" id="example-2-same-as-1-but-using-a-certificate-from-azure-key-vault">Example 2: Same as #1, but using a certificate from Azure Key Vault.</h4>

<!-- wp:paragraph -->
<p>PowerShell<code class="lang-PowerShell">$scriptParams = @{ ResourceGroupName = $ResourceGroupName Name = "wac-vm2" Credential = $Credential VirtualNetworkName = $VirtualNetworkName SubnetName = $SubnetName VaultName = $VaultName CertName = $CertName } ./Deploy-WACAzVM.ps1 @scriptParams</code></p>

<p><a class="anchor-link docon docon-link" href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/deploy-wac-in-azure#example-3-using-a-local-msi-on-an-existing-vm-to-deploy-wac"></a></p>

<h4 class="wp-block-heading heading-anchor" id="example-3-using-a-local-msi-on-an-existing-vm-to-deploy-wac">Example 3: Using a local MSI on an existing VM to deploy WAC.</h4>

<!-- wp:heading {"level":3,"className":"heading-anchor"} -->
<h3 class="wp-block-heading heading-anchor" id="requirements-for-vm-running-the-windows-admin-center-gateway">Requirements for VM running the Windows Admin Center gateway</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Port 443 (HTTPS) must be open. Using the same variables defined for script, you can use the code below in Azure Cloud Shell to update the network security group:</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>PowerShell<code class="lang-powershell">$nsg = Get-AzNetworkSecurityGroup -Name $SecurityGroupName -ResourceGroupName $ResourceGroupName $newNSG = Add-AzNetworkSecurityRuleConfig -NetworkSecurityGroup $nsg -Name ssl-rule -Description "Allow SSL" -Access Allow -Protocol Tcp -Direction Inbound -Priority 100 -SourceAddressPrefix Internet -SourcePortRange * -DestinationAddressPrefix * -DestinationPortRange 443 Set-AzNetworkSecurityGroup -NetworkSecurityGroup $newNSG</code></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a class="anchor-link docon docon-link" href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/deploy-wac-in-azure#requirements-for-managed-azure-vms"></a></p>

<!-- wp:heading {"level":3,"className":"heading-anchor"} -->
<h3 class="wp-block-heading heading-anchor" id="requirements-for-managed-azure-vms">Requirements for managed Azure VM's</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Port 5985 (WinRM over HTTP) must be open and have an active listener. You can use the code below in Azure Cloud Shell to update the managed nodes.&nbsp;<code>$ResourceGroupName</code>&nbsp;and&nbsp;<code>$Name</code>&nbsp;use the same variables as the deployment script, but you will need to use the&nbsp;<code>$Credential</code>&nbsp;specific to the VM you are managing.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>PowerShell<code class="lang-powershell">Enable-AzVMPSRemoting -ResourceGroupName $ResourceGroupName -Name $Name Invoke-AzVMCommand -ResourceGroupName $ResourceGroupName -Name $Name -ScriptBlock {Set-NetFirewallRule -Name WINRM-HTTP-In-TCP-PUBLIC -RemoteAddress Any} -Credential $Credential Invoke-AzVMCommand -ResourceGroupName $ResourceGroupName -Name $Name -ScriptBlock {winrm create winrm/config/Listener?Address=*+Transport=HTTP} -Credential $Credential</code></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a class="anchor-link docon docon-link" href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/deploy-wac-in-azure#deploy-manually-on-an-existing-azure-virtual-machine"></a></p>

<!-- wp:heading {"className":"heading-anchor"} -->
<h2 class="wp-block-heading heading-anchor" id="deploy-manually-on-an-existing-azure-virtual-machine">Deploy manually on an existing Azure virtual machine</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>Before installing Windows Admin Center on your desired gateway VM, install a SSL certificate to use for HTTPS communication, or you can choose to use a self-signed certificate generated by Windows Admin Center. However, you will get a warning when trying to connect from a browser if you choose the latter option. You can bypass this warning in Edge by clicking&nbsp;<strong>Details &gt; Go on to the webpage</strong>&nbsp;or, in Chrome, by selecting&nbsp;<strong>Advanced &gt; Proceed to [webpage]</strong>. We recommend you only use self-signed certificates for test environments.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph {"className":"alert-title"} -->
<p class="alert-title">&nbsp;หมายเหตุ</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>These instructions are for installing on Windows Server with Desktop Experience, not on a Server Core installation.</p>
<!-- /wp:paragraph -->

<!-- wp:list {"ordered":true} -->
<ol class="wp-block-list"><!-- wp:list-item -->
<li><a href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/overview">Download Windows Admin Center</a> to your local computer.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li>Establish a remote desktop connection to the VM, then copy the MSI from your local machine and paste into the VM.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li>Double-click the MSI to begin installation, and follow the instructions in the wizard. Be aware of the following:<!-- wp:list -->
<ul class="wp-block-list"><!-- wp:list-item -->
<li>By default, the installer uses the recommended port 443 (HTTPS). If you want to select a different port, note that you need to open that port in your firewall as well.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li>If you have already installed an SSL certificate on the VM, ensure you select that option and enter the thumbprint.</li>
<!-- /wp:list-item --></ul>
<!-- /wp:list --></li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li>Start the Windows Admin Center service (run C:/Program Files/Windows Admin Center/sme.exe)</li>
<!-- /wp:list-item --></ol>
<!-- /wp:list -->

<!-- wp:paragraph -->
<p><a href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/deploy/install">Learn more about deploying Windows Admin Center.</a></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a class="anchor-link docon docon-link" href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/deploy-wac-in-azure#configure-the-gateway-vm-to-enable-https-port-access"></a></p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":3,"className":"heading-anchor"} -->
<h3 class="wp-block-heading heading-anchor" id="configure-the-gateway-vm-to-enable-https-port-access">Configure the gateway VM to enable HTTPS port access:</h3>
<!-- /wp:heading -->

<!-- wp:list {"ordered":true} -->
<ol class="wp-block-list"><!-- wp:list-item -->
<li>Navigate to your VM in the Azure portal and select <strong>Networking</strong>.</li>
<!-- /wp:list-item -->

<!-- wp:list-item -->
<li>Select <strong>Add inbound port rule</strong> and select <strong>HTTPS</strong> under <strong>Service</strong>.</li>
<!-- /wp:list-item --></ol>
<!-- /wp:list -->

<!-- wp:paragraph {"className":"alert-title"} -->
<p class="alert-title">&nbsp;หมายเหตุ</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>If you chose a port other than the default 443, choose&nbsp;<strong>Custom</strong>&nbsp;under Service and enter the port you chose in step 3 under&nbsp;<strong>Port ranges</strong>.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a class="anchor-link docon docon-link" href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/azure/deploy-wac-in-azure#accessing-a-windows-admin-center-gateway-installed-on-an-azure-vm"></a></p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":3,"className":"heading-anchor"} -->
<h3 class="wp-block-heading heading-anchor" id="accessing-a-windows-admin-center-gateway-installed-on-an-azure-vm">Accessing a Windows Admin Center gateway installed on an Azure VM</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>At this point, you should be able to access Windows Admin Center from a modern browser (Edge or Chrome) on your local computer by navigating to the DNS name of your gateway VM.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph {"className":"alert-title"} -->
<p class="alert-title">&nbsp;หมายเหตุ</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>If you selected a port other than 443, you can access Windows Admin Center by navigating to https://&lt;DNS name of your VM&gt;:&lt;custom port&gt;</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>When you attempt to access Windows Admin Center, the browser will prompt for credentials to access the virtual machine on which Windows Admin Center is installed. Here you will need to enter credentials that are in the Local users or Local administrators group of the virtual machine.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>In order to add other VMs in the VNet, ensure WinRM is running on the target VMs by running the following in PowerShell or the command prompt on the target VM:&nbsp;<code>winrm quickconfig</code></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>If you haven't domain-joined the Azure VM, the VM behaves like a server in workgroup, so you'll need to make sure you account for&nbsp;<a href="https://learn.microsoft.com/th-th/windows-server/manage/windows-admin-center/support/troubleshooting#using-windows-admin-center-in-a-workgroup">using Windows Admin Center in a workgroup</a>.</p>
